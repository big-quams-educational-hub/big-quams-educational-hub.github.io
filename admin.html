Manage Admins

Creating an admin here sets up their login immediately — no separate self-registration step needed. Access Tier controls what they can do: Reporter can write new content but not edit/delete it; Editor has full control over content; Full Access adds operational tools (Site Settings, Ticker, etc). CEO isn\u2019t assignable here — it\u2019s limited to the two founder accounts by design and can\u2019t be changed from this screen. Resetting a password sends them a reset-link email (there's no way for anyone, including the CEO, to see or directly set another person's password — that's a Firebase security limit, not a gap in this panel). Suspend temporarily blocks access (reversible with Restore); Revoke removes them from the whitelist entirely — their login and profile history are kept either way.

News Writing & Formatting Rules

Type using familiar WhatsApp-style shortcuts below — they're converted into clean, professional web formatting automatically. The published article will never look like a WhatsApp chat.

Bold — *text*
  • Use for important facts, key terms, dates, names, warnings and important statements.
  • Don't bold entire paragraphs.
Italic — _text_
  • Use for light emphasis, terminology, titles, or publication names.
  • Avoid excessive italics.
Strikethrough — ~text~
  • Use to show a correction — e.g. a cancelled date or a withdrawn figure.
Monospace — `text`
  • Use for codes, portal URLs typed as text, reference/matric numbers, or short technical values.
Pull-quote — lines starting with >
  • Use to set off an official statement or a direct quote from a spokesperson.
Bulleted lists — lines starting with -
  • Use for several related items with no particular order — e.g. requirements, available courses, documents needed.
Numbered lists — lines starting with 1.
  • Use for steps, procedures, rankings, or instructions — e.g. steps for checking examination results.
Links — [descriptive text](https://example.com)
  • Always use descriptive anchor text rather than a raw URL — e.g. "Read the full admission requirements" instead of pasting the link directly.

ℹ️ How this works

Each school has its aggregate formula. Students select their school, enter JAMB + O'level scores, and calculate their aggregate. They can then download results as a PDF with the Big Quams Media® watermark — labelled as a record document, not an official result.

Bulk Upload Schools (JSON)

JSON Format

Upload a .json file containing an array of school objects. Each object must have: name, abbr, formula (50-50 / 40-60 / 60-40 / jamb-only / custom), and optionally type, location, cutoff, notes, fees, link.

[
  {
    "name": "University of Lagos",
    "abbr": "UNILAG",
    "type": "federal",
    "location": "Lagos State",
    "formula": "50-50",
    "cutoff": 200,
    "notes": "CBT — 50 questions, 30 mins.",
    "fees": "₦80,000–₦180,000/yr",
    "link": "https://unilag.edu.ng"
  }
]

Daily Hub Management

ℹ️ How Daily Hub Works

The Daily Hub page (daily.html) automatically rotates 30 built-in challenge questions by day of year — everyone gets the same question daily. The DYK facts pull from your existing dyk.json file. To add more content:

  • Add new Did You Know facts via the DYK section in this admin panel
  • The challenges auto-rotate — 30 questions cover a full month cycle
  • Students earn 5 coins per correct answer, tracked in their CBT profile
  • Daily streaks are saved to Firestore for signed-in students
